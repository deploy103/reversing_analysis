# Integration Notes

Reverse Researcher can use command-line collectors directly, but GUI disassemblers usually provide richer function context. Use the scripts in `integrations/` to export that context as JSON.

## IDA

Open the target in IDA, run `integrations/ida/revbot_export.py`, then attach the produced `*.revbot.ida.json` to analysis or solve:

```bash
python3 -m revbot.cli analyze ./challenge --extra-json ./challenge.revbot.ida.json
python3 -m revbot.cli solve ./challenge --execute --extra-json ./challenge.revbot.ida.json
```

## Ghidra

Run `integrations/ghidra/revbot_export.py` from Script Manager or headless analyzer. It exports functions, calls, string references, and imports. Direct solve mode uses these exported strings as candidates and merges exported function rankings into the solve report.

## Frida

Use `integrations/frida/hook_template.js` as a starting point for validation experiments generated by the agents:

```bash
frida -f ./sample.exe -l integrations/frida/hook_template.js --no-pause
```

## radare2

When `rabin2` or `r2` is installed, the built-in collector already uses `rabin2`. The recipe in `integrations/r2/export.r2` documents the richer commands to run manually.

## Optional CLI Tools

The core works with standard Linux tools, but these improve coverage:

- `radare2`: adds `rabin2` metadata, imports, strings, sections, and function discovery.
- `capa`: adds malware capability rules and function-level capability hints.
- `floss`: adds decoded/stack strings for malware and packed binaries.
- `Detect-It-Easy` (`diec`): adds packer/protector identification.

Check the current machine with:

```bash
python3 -m revbot.cli tools
```
